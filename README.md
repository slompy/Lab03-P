1. x += 5 - это составной оператор, а x = x + 5 полная запись. Составной оператор удобнее и надежнее, помогает избежать ошибки, ну, к примеру, в полной записи мы можем случайно сложить byte и int, чего делать нельзя.
2. Постфиксный х++ - значение переменной не изменяется сразу же в этой строчке кода, а лишь после. 
Префиксный ++х - значение переменной изменяется сразу же в этой строчке кода.
3. Результатом любого сравнения всегда является логический тип bool, который может быть равен true или false.
4. && - Оператор И. Ему необоходимо, чтобы обе части выражения были true. Если всё будет верно, оператор вернет значение true. 
|| - Оператор ИЛИ. Ему важно чтобы хотябы одна часть выражения было true. Если всё будет верно, оператор вернет значение true.
На практике, можно использовать для защиты от падения кода. Если имя пользователя не пустое, и ему больше 18, то код продолжиться, и продолжиться даже если ему нет 18. 5. Приоритет: 10 - (2 * 3) + (4 / 2)
 1) 2 * 3 = 6
 2) 4 / 2 = 2
 3) 10 - 6 = 4
 4) 4 + 2 = 6

 Код: int numberForDm = 10 - (2 * 3) + (4 / 2);
      Console.WriteLine(numberForDm);

      Выдаёт: 6
6. Это хороший тон, потому что такой код будет читать легче, и он больше будет защищен от опечаток. Условие if ((a && b) || c) быстрее прочитать и осмыслить чем if (a && b || c), здесь уже глаза разбегаются.
